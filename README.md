# 📈 MarketPulse AI

An AI-powered Indian Stock Market Intelligence Platform that provides live market insights, analytics, news intelligence, and AI-generated market summaries.

---

## 🚀 Features

- Live NSE Market Data
- Major Indices Analytics
- Market Breadth Analysis
- Sector Performance
- India VIX Analysis
- FII/DII Activity
- Technical Indicators
- AI Market Commentary
- Morning / Midday / Closing Reports
- Streamlit Dashboard (Upcoming)

---

## 🛠 Tech Stack

- Python
- Pandas
- nselib
- Streamlit
- SQLite
- OpenAI API
- Git & GitHub
